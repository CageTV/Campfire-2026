- **Hunterborn** - the original Hunterborn mod's Campfire patch, with an ESL copy. (Hunterborn 2026's own ESL edition already carries its patch.)
- **Embers XD - heat sources** - Embers XD's own `Embers XD - Patch - Campfire.esp`, with an ESL copy: with the ESL Campfire the original plugin edits the wrong records. Frostfall 2026 already covers Embers XD through its own `Frostfall_Embers_FLM.ini`; keep only one copy of this file active.
